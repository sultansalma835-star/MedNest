# MedNest 🏥
An integrated electronic pharmacy management platform.

## Tech Stack
- **Backend:** Laravel (PHP)
- **Frontend:** React.js
- **Database:** MySQL
- **APIs:** RESTful APIs tested with Postman

## Features
- Digital prescriptions with e-signatures
- OCR-based text extraction for prescription images
- Automatic drug interaction checks (Medscape data)
- Remote pharmacist consultations via in-app chat
- Order tracking from request to delivery
- Inventory management with expiry and stock alerts
